# UE-FONDEMENT-DES-R-SEAUX-et-CISCO
1) Configurer un routeur, un commutateur et des PC pour prendre en charge la  connectivité IPv4 et IPv6 pour les hôtes compatibles. 2) Créer un sous-réseau afin de fournir des adresses IPv4 pour deux sous-réseaux pouvant prendre en charge le nombre d'hôtes requis. Projets réalisés avec le logiciel Packet Tracer.
